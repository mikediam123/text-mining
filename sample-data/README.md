# Synthetic sample data

`vcu_cares_synthetic.xlsx` is a **synthetic** stand-in for the VCU CARES workbook. It lets lab members run every chapter without access to the real student responses.

It is safe to share and to commit. Every word of text was generated by `R/00-make-synthetic.R` from invented phrase banks. No real response, student, interviewer, or event name appears, and a check against the real workbook found no answer in common.

## What matches the real data

- Three sheets with the same column headers (including the swapped `Date`/`Event` headers on *Second Process* and the non-breaking spaces in some checkbox labels), so `R/01-prep-data.R` runs on it unchanged
- Same row counts: 1,021 / 79 / 141
- Interviewer topic codes ticked at the real rates, with the real number of codes per answer
- Answer lengths close to the real distribution, including the long tail
- The same mess: placeholder answers ("none," "n/a," "test"), missing answers, keyboard mashing, inconsistent student-level labels, curly apostrophes, numbered-list answers, and demographics filled in for 689 of 1,021 students

## What does not match

- **The language is repetitive.** Answers are assembled from about 150 phrases, so there is far less variety than real speech. Topic models will find tidy themes because the text was built from tidy themes.
- **Differences between groups are not real.** Level and source were assigned at random, so any TF-IDF or STM difference between undergraduates and graduates is noise.
- **No finding here says anything about VCU students.** Use it to learn the methods and check your code, not to draw conclusions.

Some noise was added on purpose (codes the text only hints at, vague answers, off-topic mentions, concerns worded as wishes) so that the supervised and sentiment chapters behave roughly as they do on real data. On the last run, topic classification AUC ranged from about 0.71 to 0.87 across topics, versus about 0.67 to 0.89 on the real data. Exact numbers in the chapter text will not match.

## Using it

```bash
Rscript R/01-prep-data.R sample-data/vcu_cares_synthetic.xlsx
```

Then render as usual. To regenerate the file (same seed gives the same output):

```bash
Rscript R/00-make-synthetic.R
```

Needs the `writexl` package.
